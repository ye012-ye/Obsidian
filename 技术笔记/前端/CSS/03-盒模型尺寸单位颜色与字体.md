# CSS 03 - 盒模型尺寸单位颜色与字体

> [!tip] 页面就是盒子套盒子
> CSS 布局的底层心智模型是盒模型。每个元素都可以看成一个盒子，盒子有内容、内边距、边框、外边距。

## 标准盒模型

一个元素从内到外有四层：

1. `content`：内容区域。
2. `padding`：内边距。
3. `border`：边框。
4. `margin`：外边距。

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid #d0d7de;
  margin: 16px;
}
```

在默认标准盒模型下，元素实际占用宽度是：

```text
实际宽度 = width + padding-left + padding-right + border-left + border-right
```

也就是 `200 + 20 + 20 + 2 + 2 = 244px`。

## 盒模型关键字认知

> [!info] 看到一个元素，先把它想成盒子
> CSS 里的很多关键词其实都在回答：内容在哪、内部留多少、边框多粗、外部离别人多远、最终占多大。

### content

内容区域。文字、图片、子元素真正显示的地方。

```css
.box {
  width: 200px;
}
```

默认标准盒模型里，`width` 控制的是 content 宽度。

### padding

内边距。内容和边框之间的距离。

```css
.button {
  padding: 8px 16px;
}
```

按钮想变得更好点、更容易点击，用 `padding`，不是用固定高度硬撑。

### border

边框。

```css
.card {
  border: 1px solid #d0d7de;
}
```

`1px solid #d0d7de` 分别表示边框宽度、边框样式、边框颜色。

### margin

外边距。元素和外部元素之间的距离。

```css
.card {
  margin-bottom: 16px;
}
```

> [!warning] padding 和 margin 的区别
> 内容贴边，用 `padding`；两个元素之间太挤，用 `margin` 或容器的 `gap`。

### gap

子元素之间的间距，常用于 Flex/Grid 容器。

```css
.list {
  display: flex;
  gap: 12px;
}
```

比给每个子元素写 `margin-right` 更清楚，也不需要处理最后一个元素的多余间距。

## `box-sizing`

项目里通常会全局设置：

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

设置后，`width` 包含 content、padding、border，尺寸更符合人的直觉。

> [!success] 推荐默认写法
> 新项目建议一开始就加 `box-sizing: border-box;`。这样写卡片、输入框、按钮时，不容易因为 padding 把宽度撑爆。

关键词认知：

| 关键词 | 含义 |
|---|---|
| `content-box` | 默认盒模型，`width` 只算内容区 |
| `border-box` | 推荐盒模型，`width` 包含内容、padding、border |
| `box-sizing` | 决定浏览器怎么计算盒子宽高 |

## margin 和 padding 怎么选

| 场景 | 推荐 |
|---|---|
| 元素内部内容和边框之间的距离 | `padding` |
| 元素和外部元素之间的距离 | `margin` |
| 按钮点击区域变大 | `padding` |
| 卡片之间拉开距离 | `gap` 或 `margin` |
| Flex/Grid 子项间距 | 优先 `gap` |

## 外边距折叠

普通文档流中，垂直方向的 `margin` 可能折叠。

```css
.a {
  margin-bottom: 20px;
}

.b {
  margin-top: 30px;
}
```

两个元素之间的距离可能是 `30px`，而不是 `50px`。

> [!warning] 现代布局少踩这个坑
> Flex 和 Grid 容器内的子元素不会发生普通块级元素那种外边距折叠。实际项目里，卡片列表间距优先用 `gap`。

## 常用尺寸单位

| 单位 | 含义 | 适合场景 |
|---|---|---|
| `px` | 固定像素 | 边框、图标、精确尺寸 |
| `%` | 相对父元素 | 宽度、布局比例 |
| `em` | 相对当前元素字号 | 字体相关局部尺寸 |
| `rem` | 相对根元素字号 | 全局字号、间距体系 |
| `vw` | 视口宽度百分比 | 全屏区域、响应式宽度 |
| `vh` | 视口高度百分比 | 首屏高度、弹窗 |
| `fr` | Grid 剩余空间份额 | Grid 布局 |

推荐：

```css
:root {
  font-size: 16px;
}

.page {
  max-width: 72rem;
  margin: 0 auto;
  padding: 0 1rem;
}
```

## 尺寸关键字认知

### width / height

设置宽高，但最终受 `box-sizing`、父元素、内容、布局模式影响。

```css
.avatar {
  width: 48px;
  height: 48px;
}
```

### min-width / max-width

限制宽度范围。

```css
.page {
  max-width: 1120px;
  margin: 0 auto;
}
```

`max-width` 常用于页面容器，避免大屏下内容太宽。`min-width: 0` 常用于 Flex/Grid 子项，防止长文本把布局撑爆。

### min-height

限制最小高度。

```css
.page {
  min-height: 100vh;
}
```

常用于让页面至少占满一屏。

### auto

`auto` 是“让浏览器按规则自动算”，不同属性含义不同。

```css
.page {
  max-width: 1120px;
  margin: 0 auto;
}
```

这里 `margin-left: auto` 和 `margin-right: auto` 会平分剩余空间，所以容器水平居中。

```css
.block {
  width: auto;
}
```

块级元素的 `width: auto` 通常表示占满父元素可用宽度。

> [!warning] auto 不是一个固定值
> `auto` 在 `width`、`height`、`margin`、Grid、Flex 里计算规则都不完全一样。看到它时要问：当前属性让浏览器自动算什么？

### calc

让 CSS 做简单计算。

```css
.main {
  min-height: calc(100vh - 64px);
}
```

适合“总高度减去头部高度”这类场景。

## 颜色写法

```css
.demo {
  color: #24292f;
  background: rgb(246, 248, 250);
  border-color: rgba(208, 215, 222, 0.8);
}
```

常见方式：

1. 十六进制：`#0969da`
2. RGB：`rgb(9, 105, 218)`
3. RGBA：`rgba(9, 105, 218, 0.2)`
4. HSL：`hsl(212 92% 45%)`

> [!success] 项目建议
> 不要到处散落颜色值。用 CSS 变量统一管理主色、文字色、边框色、背景色。

```css
:root {
  --color-text: #24292f;
  --color-muted: #57606a;
  --color-border: #d0d7de;
  --color-primary: #0969da;
}

.link {
  color: var(--color-primary);
}
```

## 字体和行高

```css
body {
  font-family:
    system-ui,
    -apple-system,
    BlinkMacSystemFont,
    "Segoe UI",
    sans-serif;
  font-size: 16px;
  line-height: 1.7;
  color: #24292f;
}
```

核心属性：

1. `font-family`：字体族。
2. `font-size`：字号。
3. `font-weight`：字重。
4. `line-height`：行高。
5. `letter-spacing`：字间距。
6. `text-align`：对齐。
7. `text-decoration`：下划线、删除线。

> [!warning] 行高建议写无单位数字
> `line-height: 1.7` 会随着当前字号自动缩放，比固定 `28px` 更灵活。

## 文字关键字认知

| 关键字 | 控制什么 | 常见用法 |
|---|---|---|
| `color` | 文字颜色 | 正文色、链接色、弱文字 |
| `font-family` | 字体族 | 全站基础字体 |
| `font-size` | 字号 | 标题、正文、辅助文字 |
| `font-weight` | 字重 | 正常、半粗、加粗 |
| `line-height` | 行高 | 控制多行文字阅读舒适度 |
| `text-align` | 文本对齐 | 居中标题、右对齐数字 |
| `text-decoration` | 文本装饰线 | 链接下划线、删除线 |

> [!info] `text-align: center` 不是万能居中
> 它让文字和行内内容居中，不会让一个块级盒子自己在父容器里居中。盒子水平居中通常用 `margin: 0 auto` 或 Flex/Grid。

## 背景

```css
.hero {
  background-color: #f6f8fa;
  background-image: url("./hero.png");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

常用组合：

1. 纯色背景：`background-color`
2. 图片铺满：`background-size: cover`
3. 图片完整显示：`background-size: contain`
4. 渐变背景：`linear-gradient(...)`

## 常用基础重置

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.7;
}

img {
  max-width: 100%;
  display: block;
}

button,
input,
textarea,
select {
  font: inherit;
}
```

## 一句话总结

> 盒模型决定元素占多大，单位决定尺寸怎么响应，颜色和字体决定页面气质；这三块是所有 CSS 布局的底盘。
