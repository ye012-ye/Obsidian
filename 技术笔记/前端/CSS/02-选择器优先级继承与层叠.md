# CSS 02 - 选择器优先级继承与层叠

> [!tip] CSS 冲突的核心问题
> 当多个规则都能选中同一个元素，并且设置了同一个属性，浏览器必须决定谁生效。决定过程主要看：来源、重要性、优先级、书写顺序。

## 常用选择器

```css
/* 标签 */
button {}

/* class */
.btn {}

/* id */
#submit {}

/* 后代 */
.toolbar button {}

/* 直接子元素 */
.menu > li {}

/* 相邻兄弟 */
h2 + p {}

/* 通用兄弟 */
h2 ~ p {}

/* 属性 */
input[type="text"] {}
```

项目里最常用的是 class、后代、子代、属性选择器。标签选择器用于 reset 或全局基础样式，ID 选择器尽量少用。

## 伪类

伪类表示元素处于某种状态。

```css
a:hover {
  text-decoration: underline;
}

input:focus {
  border-color: #0969da;
  outline: none;
}

button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

li:first-child {
  margin-top: 0;
}
```

常用伪类：

| 伪类 | 含义 |
|---|---|
| `:hover` | 鼠标悬停 |
| `:focus` | 获得焦点 |
| `:active` | 激活状态 |
| `:disabled` | 禁用状态 |
| `:checked` | 选中状态 |
| `:first-child` | 第一个子元素 |
| `:last-child` | 最后一个子元素 |
| `:nth-child()` | 第 n 个子元素 |
| `:not()` | 排除某些元素 |

## 伪元素

伪元素像是在元素内部创建一个虚拟子元素。

```css
.title::before {
  content: "";
  display: inline-block;
  width: 4px;
  height: 16px;
  margin-right: 8px;
  background: #0969da;
}

.card::after {
  content: "";
  display: block;
  clear: both;
}
```

常用伪元素：

1. `::before`：在内容前插入装饰。
2. `::after`：在内容后插入装饰。
3. `::placeholder`：输入框占位符。
4. `::selection`：选中文本时的样式。

> [!warning] `content` 不能忘
> `::before` 和 `::after` 通常必须写 `content`，即使是空字符串。不写时伪元素不会渲染。

## 继承

有些 CSS 属性会从父元素传给子元素，这叫继承。

常见可继承属性：

1. `color`
2. `font-size`
3. `font-family`
4. `font-weight`
5. `line-height`
6. `text-align`

常见不可继承属性：

1. `width`
2. `height`
3. `margin`
4. `padding`
5. `border`
6. `background`
7. `display`
8. `position`

示例：

```css
body {
  color: #24292f;
  font-family: system-ui, sans-serif;
  line-height: 1.7;
}
```

这样页面里大部分文本会自动继承这些基础文字样式。

## 优先级

优先级可以粗略记成四档：

| 类型 | 示例 | 权重直觉 |
|---|---|---|
| 行内样式 | `style="color:red"` | 很高 |
| ID 选择器 | `#app` | 高 |
| class、属性、伪类 | `.btn`、`[type=text]`、`:hover` | 中 |
| 标签、伪元素 | `button`、`::before` | 低 |

示例：

```css
p {
  color: black;
}

.intro {
  color: blue;
}

#lead {
  color: red;
}
```

```html
<p id="lead" class="intro">最终是红色</p>
```

因为 ID 选择器优先级高于 class 和标签。

## 层叠顺序

如果优先级一样，后写的覆盖先写的。

```css
.btn {
  color: blue;
}

.btn {
  color: red;
}
```

最终是红色。

> [!danger] 不要靠后写硬压
> 如果项目里到处靠“后写覆盖前面”，样式会越来越难维护。优先减少选择器复杂度，保持 class 命名清楚。

## `!important`

```css
.btn {
  color: red !important;
}
```

`!important` 会提升重要性，很容易破坏正常层叠规则。

适合场景：

1. 临时覆盖第三方库样式。
2. 工具类原子样式，如 `.hidden { display: none !important; }`。
3. 不得不处理线上紧急样式覆盖。

不适合场景：

1. 普通业务样式。
2. 为了省事压过别人。
3. 大量散落在项目里。

## 排查样式不生效

> [!success] DevTools 排查顺序
> 1. 元素有没有被选中。
> 2. 样式规则有没有出现。
> 3. 属性有没有被划掉。
> 4. 被谁覆盖了。
> 5. 属性值是否合法。
> 6. 父元素是否限制了尺寸、溢出或布局。

## 本章练习

1. 写一个按钮 `.btn`。
2. 加上 `.btn.primary` 和 `.btn.danger`。
3. 给按钮写 `:hover`、`:disabled`。
4. 用 `::before` 给标题加装饰线。
5. 故意写两个冲突规则，用 DevTools 找出谁覆盖了谁。

## 一句话总结

> CSS 不是“谁离元素近谁生效”，而是按层叠规则决策；学会看优先级，样式冲突就不再玄学。
