## VUE2 生命周期

```vue
<script setup>
	beforeCreate(){
	//创建前hook
	}
	created(){
	//创建后
	}
	beforeMount(){
	//挂载前
	}
	mounted(){
	//挂载后
	}
	beforeUpdate(){
	//更新前
	}
	updated(){
	//更新后
	}
	beforeDestroy(){
	//销毁前
	}
	destroyed(){
	//销毁后
	}
</script>
```

# Vue3 模板语法、组件基础与生命周期

> [!info] 本章抓什么
> Vue 模板不是普通 HTML，它是“HTML + 响应式表达式 + 指令”。本章重点是会写页面、会拆组件、会让父子组件通信。

## 文本插值

```vue
<script setup>
const title = "Vue3 教程";
</script>

<template>
  <h1>{{ title }}</h1>
</template>
```

模板表达式可以写简单 JS：

```vue
<template>
  <p>{{ count + 1 }}</p>
  <p>{{ isLogin ? "已登录" : "未登录" }}</p>
</template>
```

> [!warning] 模板里不要写复杂逻辑
> 复杂计算放到 `computed` 或函数里，模板只保留易读表达式。

## 属性绑定

```vue
<script setup>
const imageUrl = "/logo.png";
const isActive = true;
</script>

<template>
  <img :src="imageUrl" alt="logo" />
  <div :class="{ active: isActive }">内容</div>
</template>
```

`v-bind:` 可以简写成 `:`。

## 事件绑定

```vue
<script setup>
import { ref } from "vue";

const count = ref(0);
</script>

<template>
  <button @click="count++">点击 {{ count }}</button>
</template>
```

`v-on:` 可以简写成 `@`。

事件参数：

```vue
<button @click="handleClick($event, item.id)">删除</button>
```

## 条件渲染

```vue
<template>
  <p v-if="loading">加载中...</p>
  <p v-else-if="error">加载失败</p>
  <p v-else>加载成功</p>
</template>
```

| 指令 | 特点 |
|---|---|
| `v-if` | 条件不满足时不渲染 DOM |
| `v-show` | 一直渲染 DOM，只切换 display |

频繁切换用 `v-show`，条件变化少用 `v-if`。

## 列表渲染

```vue
<script setup>
const users = [
  { id: 1, name: "张三" },
  { id: 2, name: "李四" },
];
</script>

<template>
  <ul>
    <li v-for="user in users" :key="user.id">
      {{ user.name }}
    </li>
  </ul>
</template>
```

> [!danger] v-for 必须写稳定 key
> 不要默认用数组下标做 key。列表增删、排序、表单输入时，错误 key 会导致 DOM 复用异常。

## props

子组件 `UserCard.vue`：

```vue
<script setup>
defineProps({
  user: {
    type: Object,
    required: true,
  },
});
</script>

<template>
  <article>
    <h3>{{ user.name }}</h3>
    <p>{{ user.role }}</p>
  </article>
</template>
```

父组件：

```vue
<UserCard :user="{ name: '小明', role: '管理员' }" />
```

## emit

子组件：

```vue
<script setup>
const emit = defineEmits(["delete"]);

function handleDelete() {
  emit("delete");
}
</script>

<template>
  <button @click="handleDelete">删除</button>
</template>
```

父组件：

```vue
<UserCard :user="user" @delete="removeUser(user.id)" />
```

## 生命周期

```vue
<script setup>
import { onMounted, onUnmounted } from "vue";

function handleResize() {
  console.log(window.innerWidth);
}

onMounted(() => {
  window.addEventListener("resize", handleResize);
});

onUnmounted(() => {
  window.removeEventListener("resize", handleResize);
});
</script>
```

常用生命周期：

| Hook | 触发时机 |
|---|---|
| `onMounted` | 组件挂载后 |
| `onUpdated` | 组件更新后 |
| `onUnmounted` | 组件卸载后 |

> [!success] 创建什么，清理什么
> 定时器、事件监听、第三方实例、WebSocket 连接，都要在组件卸载时清理。

## 本章练习

1. 做一个用户列表组件。
2. 用 `v-if` 展示加载中、失败、空列表、正常列表。
3. 子组件接收 `user`，点击按钮 emit 删除事件。
4. 在 `onMounted` 中监听窗口大小，卸载时移除监听。

## 一句话总结

> 模板负责描述页面，props 负责父传子，emit 负责子通知父，生命周期负责接入和清理外部副作用。
