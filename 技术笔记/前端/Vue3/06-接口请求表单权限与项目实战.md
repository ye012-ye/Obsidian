## 请求封装

```js
// src/api/request.js
import { useUserStore } from "@/stores/user";

export async function request(url, options = {}) {
  const userStore = useUserStore();

  const response = await fetch(url, {
    headers: {
      "Content-Type": "application/json",
      Authorization: userStore.token ? `Bearer ${userStore.token}` : "",
      ...options.headers,
    },
    ...options,
  });

  if (response.status === 401) {
    userStore.logout();
    throw new Error("登录已过期");
  }

  if (!response.ok) {
    throw new Error(`请求失败：${response.status}`);
  }

  return await response.json();
}
```

接口模块：

```js
// src/api/user.js
import { request } from "./request";

export function getUsers(params) {
  const query = new URLSearchParams(params).toString();
  return request(`/api/users?${query}`);
}

export function createUser(data) {
  return request("/api/users", {
    method: "POST",
    body: JSON.stringify(data),
  });
}
```

> [!danger] 请求封装不要只处理成功
> 401、403、404、500、网络失败、业务错误码、超时、重复提交，都要有明确策略。

## 列表分页

```vue
<script setup>
import { computed, onMounted, ref } from "vue";
import { getUsers } from "@/api/user";

const page = ref(1);
const pageSize = ref(10);
const keyword = ref("");
const loading = ref(false);
const list = ref([]);
const total = ref(0);

const params = computed(() => ({
  page: page.value,
  pageSize: pageSize.value,
  keyword: keyword.value,
}));

async function loadList() {
  loading.value = true;
  try {
    const result = await getUsers(params.value);
    list.value = result.records;
    total.value = result.total;
  } finally {
    loading.value = false;
  }
}

onMounted(loadList);
</script>
```

搜索时重置页码：

```js
function handleSearch() {
  page.value = 1;
  loadList();
}
```

## 表单状态

```vue
<script setup>
import { reactive, ref } from "vue";
import { createUser } from "@/api/user";

const form = reactive({
  username: "",
  email: "",
  role: "user",
});

const submitting = ref(false);

function validate() {
  if (!form.username.trim()) return "用户名不能为空";
  if (!form.email.includes("@")) return "邮箱格式不正确";
  return "";
}

async function submit() {
  const message = validate();
  if (message) {
    alert(message);
    return;
  }

  submitting.value = true;
  try {
    await createUser(form);
    alert("保存成功");
  } finally {
    submitting.value = false;
  }
}
</script>
```

## 登录流程

典型流程：

1. 用户提交账号密码。
2. 后端返回 token 和用户信息。
3. Pinia 保存 token 和用户信息。
4. 持久化 token。
5. 跳转原目标页。
6. 请求拦截器附带 token。
7. 401 时清理登录状态并跳转登录页。

登录示例：

```js
async function login(payload) {
  const result = await request("/api/login", {
    method: "POST",
    body: JSON.stringify(payload),
  });

  userStore.setToken(result.token);
  userStore.setProfile(result.user);

  router.push(route.query.redirect || "/");
}
```

## 权限按钮

```js
// composables/usePermission.js
import { computed } from "vue";
import { useUserStore } from "@/stores/user";

export function usePermission(code) {
  const userStore = useUserStore();

  return computed(() => {
    return userStore.profile?.permissions?.includes(code) ?? false;
  });
}
```

使用：

```vue
<script setup>
import { usePermission } from "@/composables/usePermission";

const canDelete = usePermission("user:delete");
</script>

<template>
  <button v-if="canDelete">删除</button>
</template>
```

## 项目实战：用户管理

页面能力：

1. 用户列表。
2. 关键词搜索。
3. 分页。
4. 新增用户。
5. 编辑用户。
6. 删除用户。
7. 按角色控制按钮。
8. 失败提示和 loading 状态。

拆分建议：

| 文件 | 职责 |
|---|---|
| `UserListView.vue` | 页面编排、查询条件、列表状态 |
| `UserFormDialog.vue` | 新增/编辑表单 |
| `api/user.js` | 用户接口 |
| `stores/user.js` | 当前登录用户 |
| `usePagination.js` | 分页逻辑 |
| `usePermission.js` | 权限判断 |

> [!success] 写业务页的顺序
> 先接口模块，再页面状态，再渲染列表，再加搜索分页，再加新增编辑删除，最后补权限、loading、错误提示和空状态。
