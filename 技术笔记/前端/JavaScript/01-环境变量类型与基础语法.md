# JavaScript 环境、变量、类型与基础语法

> [!info] 本章抓什么
> 你要先知道 JS 在哪里运行、怎么声明变量、有哪些基础类型、条件和循环怎么写。不要一开始就背框架，前端所有框架最后都会回到这些基础语法。

## JavaScript 运行在哪里

| 环境 | 主要用途 | 你会遇到什么 |
|---|---|---|
| 浏览器 | 页面交互、DOM、事件、请求 | `window`、`document`、`fetch`、DevTools |
| Node.js | 工程脚本、服务端、构建工具 | `node`、`npm`、文件系统、包管理 |
| 构建工具 | 打包、开发服务器、热更新 | Vite、Webpack、Rollup |

最简单的运行方式是在浏览器控制台输入：

```js
console.log("Hello JavaScript");
```

或者创建一个 HTML 文件：

```html
<!doctype html>
<html lang="zh-CN">
  <body>
    <button id="btn">点我</button>
    <script>
      document.querySelector("#btn").addEventListener("click", () => {
        alert("JS 生效了");
      });
    </script>
  </body>
</html>
```

## 变量声明

现代 JS 默认用 `const` 和 `let`：

```js
const appName = "todo";
let count = 0;

count += 1;
console.log(appName, count);
```

| 写法 | 是否可重新赋值 | 作用域 | 推荐程度 |
|---|---:|---|---|
| `const` | 否 | 块级作用域 | 默认优先 |
| `let` | 是 | 块级作用域 | 需要变化时用 |
| `var` | 是 | 函数作用域 | 旧代码会见到，新代码少用 |

> [!warning] `const` 不是“对象完全不能变”
> `const user = { name: "A" }` 表示变量 `user` 不能重新指向另一个对象，但对象内部属性仍然可以改：`user.name = "B"`。

## 基础类型

JavaScript 有原始类型和对象类型。

| 类型 | 示例 | 说明 |
|---|---|---|
| `number` | `1`、`3.14`、`NaN` | 整数和小数都属于 number |
| `string` | `"hello"` | 字符串 |
| `boolean` | `true`、`false` | 布尔值 |
| `undefined` | `let x` | 声明了但没有赋值 |
| `null` | `null` | 主动表示“没有值” |
| `bigint` | `123n` | 大整数 |
| `symbol` | `Symbol("id")` | 唯一标识 |
| `object` | `{}`、`[]`、函数 | 复杂结构 |

检查类型：

```js
console.log(typeof 1); // "number"
console.log(typeof "1"); // "string"
console.log(typeof true); // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null); // "object"，这是历史遗留问题
```

> [!danger] 类型转换是 JS 高频坑
> `==` 会做隐式类型转换，初学和工程代码默认用 `===`。只有你明确知道转换规则时，再考虑 `==`。

```js
console.log(0 == false); // true
console.log(0 === false); // false
console.log("1" == 1); // true
console.log("1" === 1); // false
```

## 字符串与模板字符串

```js
const name = "小明";
const age = 18;

const message = `${name} 今年 ${age} 岁`;
console.log(message);
```

模板字符串适合拼接变量、多行文本、生成 HTML 片段。

## 条件判断

```js
const score = 86;

if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("继续加油");
}
```

三元表达式适合简单选择：

```js
const label = score >= 60 ? "通过" : "未通过";
```

## 循环

```js
const users = ["张三", "李四", "王五"];

for (let i = 0; i < users.length; i++) {
  console.log(users[i]);
}

for (const user of users) {
  console.log(user);
}
```

实际项目里，数组渲染和数据转换更多使用 `map`、`filter`、`reduce`，详见 [[03-数组对象集合与常用API]]。

## 错误阅读

常见报错：

| 报错 | 通常原因 |
|---|---|
| `ReferenceError` | 变量没定义就使用 |
| `TypeError` | 对错误类型调用方法，比如 `undefined.map` |
| `SyntaxError` | 语法写错，比如括号没闭合 |
| `RangeError` | 范围错误，比如递归太深 |

```js
const user = null;
console.log(user.name); // TypeError
```

> [!success] 调试第一步
> 看到报错先看三件事：错误类型、错误信息、报错行号。不要凭感觉乱改。

## 一句话总结

> JS 基础语法的核心不是记住每个符号，而是能稳定表达数据、条件、循环和错误。
